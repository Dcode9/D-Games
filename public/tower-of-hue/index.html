Tower of Hue

A block slides across. Place it on the tower. Whatever hangs over gets cut off, so line it up. New here? Do the tutorial.

  • Line the sliding block up with the dashed guide lines.
  • Within a few pixels is PERFECT: no cut, and the block snaps in.
  • 3 perfects in a row make the block grow back wider.
  • Miss the tower completely and it topples. Speed rises as you climb.
