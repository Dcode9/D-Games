# D'Ai's Game Suite

A collection of three interactive HTML5 games coded with precision and elegance.

## Games Included

### 1. Puzzle Master
- **Objective**: Match colored tiles to score points
- **Controls**: Click tiles to flip and match colors. Press 'R' to reset.
- **Win Condition**: Reach 20+ matches to win

### 2. Reflex Arena
- **Objective**: Catch falling blue orbs with your red paddle
- **Controls**: Use LEFT and RIGHT arrow keys to move
- **Lives**: You have 3 lives. Lose all and the game ends.

### 3. Neon Rush
- **Objective**: Avoid falling red blocks
- **Controls**: 
  - Press SPACE to start/pause
  - Use LEFT and RIGHT arrow keys to dodge
- **Progression**: Score increases difficulty with each level

## How to Play

1. Open `game-suite.html` in any modern web browser
2. Select a game using the buttons at the top
3. Follow the on-screen instructions for each game

## Installation

No installation required! Simply open the HTML file in Chrome, Firefox, Safari, or Edge.
